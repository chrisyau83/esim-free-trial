# eSIM Free Trial

A fast, accessible English guide to claiming and installing the uPhone eSIM Free Trial.

## What this repository contains

- A responsive, build-free GitHub Pages site
- A five-step claim and activation walkthrough
- Installation paths for iPhone, Google Pixel, and Samsung devices
- Troubleshooting and common eSIM questions
- Clear affiliate disclosures at the point of click

## Local preview

Run a static server from the repository root:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Affiliate link

The outbound URL is defined once in `config.js` and applied to every element with the `affiliate-link` class. It uses the approved `CHRISYAU` uPhone affiliate code and dedicated GitHub campaign tags so attribution stays consistent across the site.

## Deployment

The site is designed for GitHub Pages. In the repository settings, set Pages to deploy from the `main` branch and repository root.
